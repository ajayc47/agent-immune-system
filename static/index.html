SecuredAI.org AGENT IMMUNE SYSTEM  /  detect · explain · vaccinate · verify

When an AI agent is hijacked by a poisoned input, this proves which input caused it and ships a guardrail verified against all of production before it deploys.

1 Attack recorded

A poisoned support ticket enters the agent's context. The agent obeys it.


  
2 Detected in real time 

    
Provenance-flow query over ClickHouse: external send of sensitive data, with untrusted input present.


  
3 Causal replay: what caused it 

    
Re-run with each untrusted input removed. The item whose removal stops the leak is the cause.


  
4 Vaccine: synthesize + verify against history 

    
An open model on Akash mutates the attack. A guardrail is synthesized, then replayed against the whole corpus. Deploy only on zero false positives.
